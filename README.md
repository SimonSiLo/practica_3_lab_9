Este proyecto implementa una calculadora interactiva en javascript con diversas operaciones matematicas como suma, resta, multiplicacion, division, factorial, exponente y raiz cuadrada.
Se uso una gran variedad de ramas como la rama de la resta, suma, multiplicacion, division, factorial, exponente, raiz cuadrada y la de input, todas estas siendo necesarias.

Algunos retos presentado al momento de la creacion de las ramas fueron que al fusionar entre multiples ramas, pueden haber problemas, ya que se modificaba de una manera inapropiada el archivo index si no se tenia un especial cuidado en eso.
Aparte de que algunas funciones necesitaban que algunas otras ya estubieran implementadas en el codigo, esto se puede solucionar haciendo con anterioridad una planeacion o planificacion de lo que se hara en el trabajo.

Esta practica ayuda a demostrar la importancia del manejo adecuado de ramas en git para el desarrollo organizado en la programacion, ayudando asi al flujo de trabajo facilitando la revision de colaboraciones y haciendo un aislamiento de cambios.
